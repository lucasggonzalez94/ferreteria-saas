# FerreSaaS Web - Frontend ✅

Frontend completo del sistema FerreSaaS con Next.js 14.

## ✅ Completado

- Autenticación (login/logout)
- Dashboard con stats
- POS completo (búsqueda, carrito, checkout)
- Productos (listado, creación)
- Clientes (CRUD, saldo)
- Inventario (alertas)
- Caja (apertura/cierre)
- Compras (listado)
- Reportes (stats)

## 🚀 Instalación

**Requisito**: Tener el backend corriendo en `http://localhost:3001` (ver `../README.md` para opciones Docker/Manual).

```bash
npm install
cp .env.example .env.local
npm run dev
```
